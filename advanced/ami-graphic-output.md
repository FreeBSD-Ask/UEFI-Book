# AMI Graphic Output Protocol Policy（AMI 显卡输出协议行为）

AMI 是该 BIOS 的开发商安迈。Graphic Output Protocol 即 GOP。

黑苹果可能会用到此设置。用于控制 BIOS 的输出画面。

## Output Select（输出选择）

BIOS 输出显卡。

会列出所有接入的显卡。

## Brightness Settings（亮度设置）

选项：

20/40/60/80/100/120/140/160/180/200/220/240/255

说明：

BIOS 输出亮度。

## BIST Enable（启用）

选项：

Disable（禁用）

Enable（启用）

说明：

启动或停止集显上的 BIST（内建自检）。
