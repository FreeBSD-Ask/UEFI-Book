# 键盘帮助（底部右侧）

底部右侧的键盘帮助区域列出了 BIOS 界面中常用的操作快捷键，帮助用户快速导航和操作 BIOS 界面。

- →↑↓←：Select Screen / Item（选择页面/项目）

- Enter：Select（选择）

- +/-：Change Opt.（更改选项）

- F1：General Help（常规帮助）

- F2：Previous Values（上一次的值）

- F3：Optimized Defaults（加载优化默认值）

- F4：Save & Exit（保存并退出）

- ESC：Exit（退出）

- K/k：对右上角的提示内容向上翻页
- M/m：对右上角的提示内容向下翻页
